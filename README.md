# Cyborg-Themed Landing Page Development

A modern, responsive cyberpunk landing page built with semantic HTML, modern CSS, and lightweight JavaScript interactions.

## Features

- Cyberpunk/cyborg aesthetic with dark gradients and neon cyan/magenta/purple accents
- Sticky responsive navigation with mobile menu support
- Animated hero with scanline and particle effects
- Dedicated sections for Features, Services, Testimonials, and Contact CTA
- Scroll reveal animations, card hover states, and glowing CTA buttons
- Mobile-first responsive breakpoints:
  - Mobile: `< 768px`
  - Tablet: `768px - 1023px`
  - Desktop: `>= 1024px`
- Accessibility improvements: semantic landmarks, ARIA labels, skip link, reduced-motion support

## File Structure

- `index.html` – semantic page structure and content
- `styles.css` – theme variables, responsive layout, and animations
- `script.js` – menu toggle, reveal-on-scroll, and particle generation

## Run Locally

Open `index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
